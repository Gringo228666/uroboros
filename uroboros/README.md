# УРОБОРОС — сайт студии веб-дизайна с восемью переключаемыми стилями

**Логотип** — змей, кусающий свой хвост (inline SVG в шапке и подвале, перекрашивается под стиль,
крутится при наведении). **Слоган** — «Меняем кожу, а не суть»: в шапке рядом с названием и в подвале.

Одностраничный сайт для продажи дизайна сайтов. Наверху страницы — плашки с восемью стилями.
Клик по плашке (или клавиши `1`–`8`) полностью перестраивает страницу: цвет, типографика,
границы, тени, фоновые эффекты и интерактивный виджет в разделе «Лаборатория».
**Текст при этом не меняется** — меняется только форма, как вы и просили.

## Как открыть

Просто откройте `index.html` двойным кликом — сайт заработает без сервера
(шрифты подгружаются из Google Fonts, нужен интернет).

## Редактор сайта (admin.html)

Всё, что меняется часто — очередь и свободные слоты, контакты, цены, тарифы, работы,
текст первого экрана — лежит в файле `content.js`, а правится через удобную форму.

**Как запустить:** двойной клик по **«Редактор сайта.bat»**. Откроется чёрное окно
(это локальный сервер, не закрывайте его, пока работаете) и сама админка в браузере.
Закончили — закройте окно или нажмите в нём Ctrl+C.

В редакторе:

- слева — поля: статус и очередь, контакты, первый экран, цифры, тарифы, работы, калькулятор;
- справа — живой предпросмотр строки статуса и окно с самим сайтом;
- кнопка **«Сохранить в content.js»** (или Ctrl+S) записывает изменения прямо в файл —
  первый раз браузер спросит, какой файл перезаписать: выберите `content.js` в папке сайта;
- **«Скопировать код»** кладёт готовое содержимое файла в буфер обмена;
- **«Сбросить»** возвращает поля к тому, что записано в файле.

После сохранения нажмите «Обновить предпросмотр» — сайт покажет новые данные.

Админку можно открыть и двойным кликом по `admin.html`, без bat-файла. Тогда браузер
не сможет писать в файл напрямую и кнопка «Сохранить» просто скачает `content.js` —
его нужно будет положить в папку сайта вместо старого.

**Очередь на сайте.** Числа из блока «Статус и очередь» показываются строкой над
заголовком первого экрана («Очередь: 2 проекта · свободно 3 слота · старт 15 сентября»),
в панели кибер-стиля и по команде `queue` в терминале матричного стиля. Выключатель
«Принимаем заказы» меняет строку на текст о паузе и гасит зелёный индикатор.

## Файлы

| Файл | Что внутри |
|------|-----------|
| `index.html` | вся разметка и весь текст сайта |
| `styles.css` | базовый слой: сетка, компоненты, адаптив. Первая строка подключает `themes.css` |
| `themes.css` | восемь стилей: токены и украшения каждого |
| `app.js` | переключение стилей, фоновые эффекты, виджеты, калькулятор, форма |
| `content.js` | данные сайта: очередь, контакты, цены, тарифы, работы (правится редактором) |
| `admin.html` | редактор сайта |
| `serve.ps1` + `Редактор сайта.bat` | локальный запуск редактора в один клик |
| `референс/` | ваши исходные референсы (в сайте не используются) |

## Восемь стилей

| № | Ключ | Стиль | Фоновый эффект | Виджет в «Лаборатории» |
|---|------|-------|----------------|------------------------|
| 1 | `cyber` | Кибер-брутализм | сканлайны, сетка, редкий глитч, часы в шапке | панель загрузки студии со сканированием и логом |
| 2 | `swiss` | Брутализм | красный квадрат-курсор | типографическая шкала: ползунок кегля, смена слова, инверсия |
| 3 | `paper` | Газета | бумажное зерно | наборный цех: печатная машинка и штамп «В НОМЕР» |
| 4 | `matrix` | Матрица | падающие символы на canvas | терминал с командами (`help`, `price`, `works`, `time`, `order`, `whoami`, `clear`) |
| 5 | `apple` | Минимализм | параллакс макета | конфигуратор пакета с наклоном карточки за курсором |
| 6 | `y2k` | Y2K / сцена | блёстки за курсором, звёзды, радужная бегущая строка | счётчик посетителей, взрыв блёсток, гадалка на стиль |
| 7 | `neo` | Neocities | плывущие ✿ и ☁ | пиксельный питомец и гостевая книга (сохраняется в браузере) |
| 8 | `custom` | Свой стиль (нейтральный) | нет, намеренно | анкета на персональный дизайн: ответы переносятся прямо в бриф |

Восьмая плашка — для тех, кому не подошёл ни один из семи. Она включает нейтральный
чёрно-белый режим, показывает под плашками блок «Ни один из семи стилей не подошёл?»
с кнопкой на анкету, а в «Лаборатории» вместо виджета появляется анкета: тон, характер,
плотность, движение и любимые сайты. Кнопка «Перенести в бриф» складывает ответы
в поле «Задача проекта» и прокручивает к форме.

Выбранный стиль запоминается в `localStorage` — при возврате на сайт он восстановится.

## Что править чаще всего

- **Очередь, контакты, цены, тарифы, работы, первый экран** — через редактор (`admin.html`)
  или руками в `content.js`.
- **Остальные тексты** (услуги, процесс, отзыв, вопросы) — прямо в `index.html`.
- **Цены калькулятора** — в `content.js`, блок `calc` (базовые цены, надбавка за экран,
  процент предоплаты). Список доп-опций — в `index.html`, блок `.opts`.
- **Цвета и шрифты стиля** — `themes.css`, блок токенов в начале каждого стиля
  (`--bg`, `--fg`, `--accent`, `--f-display`, `--radius` и т. д.).
- **Бегущая строка стиля** — `app.js`, объект `THEMES`, поле `ticker`.

### Добавить свой девятый стиль

1. В `app.js` добавьте ключ в `THEMES` и в массив `ORDER`.
2. В `index.html` добавьте кнопку-плашку `<button class="chip" data-set-theme="ключ">`.
3. В `themes.css` опишите блок `:root[data-theme="ключ"] { … }` с токенами.
   (В `styles.css` плашки уже раскладываются в сетку `repeat(8, …)` — при девятом стиле поправьте её.)
4. По желанию добавьте `EFFECTS.ключ` (фоновый эффект) и `WIDGETS.ключ` (виджет) в `app.js`.

> Важно: селекторы тем начинаются с `:root`, потому что `themes.css` подключается
> через `@import` и без `:root` базовые токены перебивали бы стили.

## Форма заявки

Сейчас форма проверяет поля и показывает сообщение об отправке, но никуда данные не шлёт —
бэкенда нет. Чтобы заявки приходили, в `app.js` в `initForm()` вместо показа сообщения
отправьте данные через любой сервис-приёмник форм (Formspree, Getform, Telegram Bot API)
или на собственный обработчик.

## Публикация

Сайт статический — подойдёт любой бесплатный хостинг: GitHub Pages, Netlify, Vercel,
Cloudflare Pages, Timeweb. Загрузите папку целиком (кроме `референс/`, если не нужна).
